I referred to the assignment document for all technical and design requirements.

I decided to design the full hardware in Altium Designer even though the assignment suggested using open-source software, since the final submission format was in PDF.

I created a new schematic project and added the required components as per the NPM1100-based power management circuit.

The schematic included the IC, passive components, LEDs for status indication, input headers, and a battery voltage sensing section.

I then annotated and assigned designators to all schematic components properly and generated the Bill of Materials from Altium.

After completing the schematic, I created the PCB layout from the schematic sheet.

In the PCB editor, I arranged all SMD components only on the top layer and followed proper design rules for spacing and track width.

I carefully routed top and bottom layers, ensuring the power lines were thicker and signals shorter.

I verified the design using Electrical Rule Check and Design Rule Check to ensure there were no clearance or connectivity errors.

After successful verification, I generated the top layer and bottom layer PDFs separately, each in one page as per the submission instruction.

I exported the schematic as Schematic.pdf and the layout as pcb_design.pdf from Altium using the Smart PDF export option.

The BOM file was exported in CSV format with part designator, quantity, and part number columns to meet assignment requirements.

Finally, I finalized all documentation in PDF format and verified that the files met all given restrictions before preparing them for GitHub upload.
